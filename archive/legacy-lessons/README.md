# Archiwalne aliasy lekcji

Ten katalog przechowuje stare kopie lekcji, które miały ten sam numer co
kanoniczna ścieżka `101+`. Nie są częścią kolejności kursu, testu walidacyjnego
ani linków dla ucznia. Pozostawiamy je tylko jako lokalny punkt odniesienia przy
porównywaniu wcześniejszych przykładów; nowe ćwiczenia należy zaczynać od
folderów opisanych w głównym [README](../../README.md).

W katalogu głównym każdy numer ma teraz dokładnie jeden folder. Lekcje `01–22`
zostały usunięte zgodnie z aktualną numeracją.
