Najpierw 5 prostych wzorów — czysty CSS

Zanim użyjesz generatora, przepisz te małe przykłady do pustego pliku HTML. W każdym wzorze rodzic dostaje display: flex, a reguły flex dotyczą jego bezpośrednich dzieci.

1. Oś główna i oś poprzeczna

ABC 
.parent {
  display: flex;
  flex-direction: row;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Przy row main axis biegnie w prawo. justify-content działa na tej osi, a align-items na osi poprzecznej.

2. Proporcja 5:7

5 części7 części 
.layout {
  display: flex;
  gap: 1rem;
}
.sidebar { flex: 5 1 0; }
.content { flex: 7 1 0; }

To nie jest 5% i 7%. Po odjęciu gap wolna szerokość dzieli się na 12 części: 5 dla panelu i 7 dla treści (około 42% / 58%).

3. flex-grow — wolne miejsce

grow 1grow 2grow 1 
.parent { display: flex; gap: 1rem; }
.card { flex: 1 1 0; }
.card--wide { flex-grow: 2; }

grow dzieli dodatnią wolną przestrzeń. Wartość 2 dostaje dwa udziały, ale nie oznacza zawsze dwa razy większego pudełka.

4. wrap — nowe wiersze

karta 1karta 2karta 3 
.parent {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card { flex: 1 1 12rem; }

flex-basis mówi, od jakiej szerokości zacząć. Gdy brakuje miejsca, wrap przenosi całe dzieci do kolejnej linii.

5. Strona: header, main, footer

headermain: flex 1footer 
.page {
  display: flex;
  flex-direction: column;
  min-height: 18rem;
}
main { flex: 1; }

Przy column main axis biegnie w dół. main { flex: 1 } zabiera wolne miejsce, więc stopka zostaje na dole.

  1. Najpierw wskaż rodzica i jego bezpośrednie dzieci.
  2. Dodaj display: flex oraz wybierz row albo column.
  3. Na rodzicu ustaw gap, justify-content i align-items.
  4. Na dziecku ustaw flex, flex-grow albo flex-basis.
  5. Dopiero potem włącz wrap i sprawdź wąski ekran.
