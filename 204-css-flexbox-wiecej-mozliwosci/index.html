Osobne zagadnienie: order zmienia kolejność

To przykład kolejności, nie wyrównania. W HTML jest 1 → 2 → 3. Drugi element ma order: -1 , pozostałe domyślne order: 0 , więc wizualnie otrzymujemy 2 → 1 → 3.

  1. Pierwszy w HTML
  2. Drugi w HTML, pokazany wcześniej przez CSS
  3. Trzeci w HTML

Uwaga: order zmienia tylko widok. Klawiatura i czytnik ekranu zachowują kolejność HTML, dlatego ważną treść układaj poprawnie przede wszystkim w dokumencie.

align-items a align-content — co właściwie się przesuwa?

Linia Flexbox to grupa dzieci, które zmieściły się obok siebie. Tutaj flex-direction: row , więc A + B tworzą pierwszy wiersz, a C + D drugi. Wszystkie litery są bezpośrednimi dziećmi jednego kontenera: nie dodajemy osobnych elementów HTML na wiersze.

Oś główna →, oś poprzeczna ↓. Obie porównywane właściwości działają tutaj w pionie. align-items wyrównuje dzieci w ich wierszu, a align-content ustawia całe wiersze wewnątrz kontenera.

Każda ramka poniżej ma tę samą wysokość 260px . A i C mają 48px , B i D 88px . Jasnoszare tło pokazuje wolną przestrzeń.

1. Punkt wyjścia

align-items: flex-start;
align-content: flex-start;
A · 48px
B · 88px
C · 48px
D · 88px

A i C zaczynają się przy górnej krawędzi swojej linii. B i D są wyższe (88px) i wyznaczają wysokość linii. Obie linie leżą u góry kontenera.

2. Zmieniamy tylko align-items

align-items: center;
align-content: flex-start;
A · 48px
B · 88px
C · 48px
D · 88px

A i C przesunęły się o 20px w dół: (88 − 48) / 2. Są teraz wyśrodkowane względem B i D. Całe linie zostały w tych samych miejscach.

3. Teraz zmieniamy tylko align-content

align-items: center;
align-content: space-between;
A · 48px
B · 88px
C · 48px
D · 88px

Druga linia (C i D razem) przesunęła się na dół kontenera. A i C nadal są wyśrodkowane w swoich liniach. Dodatkowa wolna przestrzeń trafiła między linie.

Porównaj 1 → 2: przesuwają się tylko krótsze dzieci. Porównaj 2 → 3: przesuwa się cały drugi wiersz.

Wspólny HTML i CSS — odtwórz przykład 
<div class="alignment-demo">
  <div class="demo-child short">A</div>
  <div class="demo-child tall">B</div>
  <div class="demo-child short">C</div>
  <div class="demo-child tall">D</div>
</div>

* { box-sizing: border-box; }
.alignment-demo {
  display: flex;
  flex-direction: row;
  flex-wrap: wrap;
  height: 260px;
  padding: 12px;
  border: 2px solid #64748b;
  gap: 12px;
  align-items: flex-start;
  align-content: flex-start;
}
.demo-child { flex: 0 0 calc(50% - 6px); }
.short { height: 48px; }
.tall { height: 88px; }
/* Teraz podmień obie wartości align według panelu 2 lub 3. */

Kiedy różnicy nie widać?

  • Gdy wszystkie dzieci są jednakowo wysokie i linia nie ma dodatkowej wysokości, align-items: center może wyglądać tak samo jak flex-start . Dlatego w tym przykładzie celowo mamy dwa rozmiary.
  • Przy flex-wrap: nowrap właściwość align-content nie działa. Samo zawijanie tekstu wewnątrz dziecka nie tworzy nowej linii Flexbox.
  • Jeśli linie zajmują już całą wysokość, nie zostaje miejsce do rozdzielenia przez align-content . Dla column rozumowanie obracamy: oś poprzeczna jest pozioma.
