CSS Grid — układ w dwóch wymiarach

Grid opisuje wiersze i kolumny, gdy Flexbox lepiej opisuje jedną oś.

Linie i komórki

grid-template-columns tworzy ścieżki kolumn, a gap rozdziela elementy.

Zmień wartości w style.css i przewiduj, która karta się przesunie.

Karty w siatce

Kolumny

repeat(3, minmax(0, 1fr)) tworzy trzy elastyczne kolumny.

Wiersze

grid-column: 1 / -1 pozwala nagłówkowi przejść przez całą szerokość.
