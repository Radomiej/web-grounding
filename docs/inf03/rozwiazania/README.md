# INF.03 — paczki z rozwiązaniami

W tym katalogu znajduje się **70 publicznych paczek `rozwiazanie.zip`**
pobranych z indeksu EE-Informatyk. Każda paczka leży w folderze o tym samym
identyfikatorze co wariant w [`../arkusze.md`](../arkusze.md), np.:

```text
rozwiazania/
└── inf03-2025-czerwiec-01/
    └── rozwiazanie.zip
```

Paczki są oddzielone od [arkuszy i materiałów startowych](../arkusze.md):

- `../arkusze/<wariant>/arkusz.pdf` — treść polecenia;
- `../arkusze/<wariant>/pliki.zip` — pliki, od których zaczyna się pracę;
- `./<wariant>/rozwiazanie.zip` — przykładowe rozwiązanie do porównania po
  własnej próbie.

## Jak korzystać

Najpierw rozwiąż zadanie samodzielnie i zachowaj własną kopię katalogu.
Paczki rozpakowuj do osobnego folderu, a rozwiązanie porównuj z PDF-em oraz
kluczem, jeżeli klucz jest dostępny. Gotowy kod jest pomocą dydaktyczną, nie
zamiennikiem ćwiczenia procesu egzaminacyjnego.

Paczki pochodzą z publicznego serwisu EE-Informatyk i nie są oficjalnymi
rozwiązaniami CKE. Zachowano oryginalne nazwy i strukturę plików; przy dalszym
udostępnianiu zachowaj [link do źródła](https://ee-informatyk.pl/inf03-ee09/praktyka/).
