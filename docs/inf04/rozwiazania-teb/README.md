# INF.04 — paczki z rozwiązaniami TEB

Ten katalog zawiera **37 publicznych paczek z rozwiązaniami** z repozytorium
[Technikum TEB — INF.04-rozwiazania](https://github.com/Technikum-TEB-Edukacja-we-Wroclawiu/INF.04-rozwiazania).
Zachowana została oryginalna ścieżka repozytorium, więc folder pokazuje także
wybraną platformę lub język (`konsola`, `desktopowa`, `mobilna`, `web`, `cpp`,
`java`, `C#`, `Python`, `Angular`, `React`).

Archiwa `.zip` i `.7z` są gotowymi projektami referencyjnymi. Nie każdy z 26
lokalnych wariantów arkusza ma publiczną paczkę rozwiązania — pobrano tylko
to, co repozytorium TEB udostępnia wprost. Warianty `AG`/`AD` nie są osobno
dublowane.

## Jak korzystać

Najpierw wykonaj zadanie z [własnego arkusza](../arkusze.md), korzystając z
[materiałów startowych](../materialy/README.md). Dopiero potem rozpakuj
odpowiednią paczkę z tego katalogu i porównaj organizację projektu, kod oraz
wynik z kryteriami oceniania. Rozwiązania są publicznymi materiałami
edukacyjnymi, nie kluczem CKE ani gwarancją jedynej poprawnej implementacji.
