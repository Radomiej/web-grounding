# INF.04 — informator i arkusze

INF.04 **Projektowanie, programowanie i testowanie aplikacji** jest
kwalifikacją technika programisty.
W tym katalogu znajdziesz arkusze praktyczne, zasady oceniania oraz wybrane
archiwa z plikami startowymi oraz wybrane paczki z rozwiązaniami. Zacznij od
[indeksu 26 arkuszy SG/SD](./arkusze.md).

## Co zawiera katalog

- [`arkusze.md`](./arkusze.md) — tabela wariantów z krótkim opisem rodzaju
  aplikacji, linkiem do pełnego PDF-u i zasad oceniania;
- [`arkusze/`](./arkusze/) — jeden katalog na wariant, np.
  `inf04-2026-styczen-02`;
- [`materialy/`](./materialy/) — publiczne archiwa plików startowych z
  mapowaniem do zadań.
- [`rozwiazania-teb/`](./rozwiazania-teb/README.md) — 37 publicznych paczek
  referencyjnych z repozytorium TEB dla wybranych wariantów i platform.

PDF arkusza jest wiążącym opisem zadania. Oznaczenie `SG` oznacza sesję
główną, a `SD` — sesję dodatkową. Warianty z większą czcionką (`AG`/`AD`)
nie są dublowane, gdyż mają tę samą treść.

Materiały pochodzą z publicznych indeksów [EE-Informatyk](https://ee-informatyk.pl/inf04/praktyka/),
[zawodowe.edu.pl](https://zawodowe.edu.pl/arkusze-praktyczne/inf-04/) oraz
[repozytorium TEB na GitHubie](https://github.com/Technikum-TEB-Edukacja-we-Wroclawiu/INF.04-rozwiazania).
Paczki z rozwiązaniami są zebrane osobno w [`rozwiazania-teb/`](./rozwiazania-teb/README.md)
i dotyczą tylko publicznie dostępnych wariantów.
