# Rozszerzenie frontend — kryteria odbioru

Cel: lokalny kurs, samodzielne HTML/CSS/JS, bez frameworków i serwera aplikacyjnego.

| AC / PIT       | Wymaganie              | Scenariusze i dowód                                            |
| -------------- | ---------------------- | -------------------------------------------------------------- |
| AC-01 / PIT-03 | Sandbox i osie         | row/column/reverse, wrap, 0–20 dzieci, reset, ograniczenia     |
| AC-02 / PIT-18 | Eksport                | pięć presetów, bezpieczny tekst, niezależny HTML/CSS           |
| AC-03 / PIT-02 | Progresja 12 lekcji JS | podstawy → DOM → obliczenia → projekt → Canvas; linki i README |
| AC-04 / PIT-03 | Formularze i zapis     | puste/błędne dane, usuwanie, storage niedostępny/uszkodzony    |
| AC-05 / PIT-21 | Canvas i HUD           | DPR, resize, ruch, pauza, reset, utrata fokusu, nakładka HTML  |
| AC-06 / PIT-09 | Responsywność          | 390×844 i 1440×900, fokus, klawiatura, lokalne pliki i HTTP    |

PHP runtime i publikacja nie są częścią tej implementacji. Brak dokładnego mapowania projektu Linear/Notion: brak zapisów zewnętrznych.
