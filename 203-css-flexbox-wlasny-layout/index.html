Trzy przepisy, które możesz przepisać

Każdy przykład ma jednego rodzica i bezpośrednie dzieci. Najpierw wpisz regułę rodzica, potem reguły dzieci.

5:7 — panel i treść

57 
.layout { display: flex; gap: 1rem; }
.panel { flex: 5 1 0; }
.content { flex: 7 1 0; }

5 + 7 = 12. Po odjęciu odstępu treść otrzymuje 7/12 wolnej szerokości, a panel 5/12. To proporcja, nie stałe piksele.

Grow — dopełnij wolne miejsce

121 
.cards { display: flex; gap: 1rem; }
.card { flex: 1 1 0; }
.card--wide { flex-grow: 2; }

Dwójka dostaje dwa udziały nadwyżki. Najpierw sprawdź, ile zostaje po bazach i gap.

Wrap — karty bez breakpointu

ABC 
.cards {
  display: flex;
  flex-wrap: wrap;
  gap: 1rem;
}
.card { flex: 1 1 14rem; }

Gdy rodzic jest węższy niż suma baz, całe dziecko przechodzi do następnej linii.
