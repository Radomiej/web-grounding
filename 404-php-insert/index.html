PHP API — dodawanie oferty do bazy

Formularz wysyła JSON metodą POST. PHP sprawdza dane, wykonuje bezpieczny INSERT i odsyła nowy numer rekordu.

1. Dodaj ofertę

Maksymalnie 100 znaków — tak samo jak w tabeli SQL.

2. Sprawdź wynik

Dane nie zostały jeszcze pobrane.

    Co dzieje się po kliknięciu?

    1. JavaScript odczytuje pola formularza przez FormData.
    2. fetch() wysyła JSON do api.php.
    3. PHP waliduje wartości i używa przygotowanego zapytania.
    4. MySQL zapisuje rekord, a PHP zwraca status 201 i ID.
